# Wedding invitation — Анна & Михаил

Статическое свадебное приглашение, подготовленное для GitHub Pages. Сайт не
требует Node.js, сборщика, базы данных или сторонних шрифтов.

## Персонализация

1. Замените имена, тексты, дату, место и программу в `index.html`.
2. Измените `EVENT_DATE`, ссылки на карту и маршрут в `site-config.js`.
3. Обязательно замените `RSVP_EMAIL` в `site-config.js` на настоящий адрес —
   сейчас там безопасный демонстрационный адрес `hello@example.com`.
4. При необходимости разрешите индексацию: удалите `noindex, nofollow` из
   `index.html` и измените `robots.txt`.

GitHub Pages — статический хостинг, поэтому RSVP готовит письмо в почтовом
приложении гостя. Для серверного хранения ответов подключите Formspree,
Formspark, собственный API или другую форму-сервис.

## GitHub Pages

Workflow `.github/workflows/pages.yml` публикует сайт при каждом push в `main`.
В настройках репозитория выберите **Settings → Pages → Source: GitHub Actions**.

Ожидаемый адрес проекта:

`https://vidalost.github.io/Prov/`

## Локальная проверка

```bash
python3 -m http.server 4173
```

Затем откройте `http://localhost:4173/`.
