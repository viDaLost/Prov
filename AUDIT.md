Дата проверки: 6 августа 2026 года.

## Итог

Сайт готов к публикации как статический проект GitHub Pages. Критических
дефектов в разметке, сценариях, локальных ресурсах и workflow не обнаружено.
Основные файлы страницы весят около 51 КБ без сжатия; внешние библиотеки,
шрифты, трекеры, cookies и фоновые сетевые запросы отсутствуют.

## Доступность

- Основной текст, акцентные подписи и кнопки соответствуют контрасту WCAG AA;
  минимальная проверенная пара для обычного текста — 4.72:1.
- Навигация, анкета и все действия доступны с клавиатуры.
- Декоративные SVG скрыты от скринридера, а дата размечена элементом `time`.
- При отключённом JavaScript контент остаётся доступным; карта и маршрут имеют
  рабочие резервные ссылки.
- При `prefers-reduced-motion: reduce` анимации и плавная прокрутка отключаются.

## Производительность

- Начальная загрузка не зависит от CDN, веб-шрифтов и сторонних JavaScript SDK.
- Иллюстрации выполнены встроенными SVG и CSS, поэтому не требуют тяжёлых
  растровых изображений.
- Общий объём ключевых ресурсов без gzip/Brotli — примерно 51 КБ:
  HTML 17.8 КБ, CSS 26.7 КБ, JavaScript 5.2 КБ, SVG 0.4 КБ.
- GitHub Pages автоматически обслуживает статические файлы через CDN и HTTPS.

## Безопасность и приватность

- Добавлена ограничительная Content Security Policy: только локальные скрипты,
  стили, изображения и шрифты; сетевые подключения страницы запрещены.
- Внешние ссылки, открывающиеся в новой вкладке, используют
  `rel="noopener noreferrer"`.
- Referrer отключён, секретов и персональных данных в репозитории нет.
- Демонстрационный email не отправляет данные. До рассылки приглашения нужно
  указать настоящий `RSVP_EMAIL` или подключить согласованный сервис форм.

## SEO и публикация

Для демо включены `noindex, nofollow` и запрет индексации в `robots.txt`. Это
защищает незавершённые персональные данные от поисковых систем. Перед публичным
запуском при необходимости:

1. заменить имена, дату, место, тексты и email;
2. убрать `noindex, nofollow` и обновить `robots.txt`;
3. добавить `og:image`, `og:url` и canonical URL после утверждения домена;
4. проверить опубликованную страницу вручную в актуальных Safari, Chrome и на
   реальном мобильном устройстве.

Визуальный cloud-preview локального GitHub Pages-проекта был недоступен из-за
политики среды проверки; ограничение не затрагивает исходники или публикацию.
Поэтому финальная кроссбраузерная визуальная проверка оставлена обязательным
пунктом после развёртывания.
